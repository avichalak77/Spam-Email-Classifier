# 📧 Spam Email Classifier

A Machine Learning project that classifies emails/SMS as **Spam** or **Not Spam (Ham)** using **Naive Bayes** and **NLP techniques**.

---

## 📌 Features
- Text preprocessing
- TF-IDF vectorization
- Naive Bayes classifier
- High accuracy spam detection

---

## 🧠 Technologies Used
- Python
- Pandas
- Scikit-learn
- NLP (TF-IDF)

---

## 📂 Dataset
SMS Spam Collection Dataset  
Each message is labeled as:
- `spam`
- `ham`
